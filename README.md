✈️ Flight Management Booking System

This project is a full-stack Flight Management Booking System designed to demonstrate the practical application of database management systems, backend development, and modern frontend technologies.

The system allows passengers to browse flights, create bookings, and make payments, while providing dedicated dashboards for employees (crew) and administrators to manage operational data securely.

🔧 Technologies Used

Frontend: React (Vite, React Router, modern UI components)

Backend: PHP (RESTful APIs)

Database: MySQL (Relational Database Design)

Server: Apache (XAMPP – Localhost)

Other: Role-Based Access Control (RBAC), JSON APIs

👤 User Roles & Features
Passenger

Register and log in

View available flights

Book flights

Make payments

View personal booking and payment history

Crew (Employee)

Access crew dashboard

View all bookings

View and manage payments

Monitor flight and passenger information

Administrator

Full system access

Create, edit, and delete crew accounts

Manage users and assign roles

View and control bookings and payments

Access administrative dashboard with statistics

🗄️ Database Design

The database is fully normalized and includes core entities such as:

Users

Passengers

Crew

Flights

Bookings

Payments

Airports

Relationships are enforced using primary keys and foreign keys to ensure data consistency and integrity.

🔐 Security & Access Control

The system implements role-based access control (RBAC).
Each user is redirected to specific pages depending on their role (passenger, crew, or admin), ensuring that sensitive operations are restricted to authorized users only.

🎯 Project Objective

The main goal of this project is to apply DBMS concepts in a real-world scenario, combining:

Database modeling (ERD)

SQL (DDL, DML, constraints)

Backend API development

Frontend user interaction

Secure role management

This project reflects how a real flight booking platform could be structured and managed using modern web technologies.
